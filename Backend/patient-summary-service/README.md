# patient-summary-service

`POST /api/patients/<id>/summary` — returns a short French summary of a
patient's completed-appointment history, generated by a local Ollama model.

Same anonymization rules as `../../summary-lab` (no name/CIN/phone/email/
address/exact birth date reaches the model — see `summary/services/
anonymize.py` and `dossier.py`). Uses the general-purpose `qwen2.5:7b` model
by default; once `summary-lab` has produced a real fine-tune, set
`SUMMARY_MODEL=mediassist-summary` in `.env` and restart.

Stateless — no database of its own, only reads the shared `mediassist`
Postgres DB read-only.

## Manual test

```bash
docker exec mediassist_patient_summary curl -s -X POST http://localhost:8300/api/patients/1/summary
```
